What is Editor Extension Manager?

Q2A Editor Extension enhances Manager Question2Answer by bringing advanced editor support to areas that normally use plain text fields, such as user wall posts, wall post comments (with the WPC plugin), and private messages.

It allows admins to use existing Q2A editors such as Markdown Editor or WYSIWYG Editor in these sections, while also adding YouTube embedding and emoji support for a more modern communication experience.

Key Features

  • Extended Editor Support
    Use Q2A editors beyond questions and answers, including: User wall posts, Private messages, Wall post comments (via WPC plugin)
  • Works With Existing Editors
    Compatible with installed Q2A editor modules such as: Markdown Editor, WYSIWYG Editor, Basic Editor
  • YouTube Video Embeds
    Users can insert YouTube videos directly inside messages and wall posts using a simple toolbar button or shortcode.
  • Emoji Support
    Built-in emoji picker with shortcode support such as: :smile: :heart: :thumbsup:
  • Automatic Shortcode Parsing
    Converts YouTube and emoji shortcodes automatically across: Questions, Answers, Comments, Messages, Wall posts
  • Admin Editor Controls
    Choose different editors independently for: Wall posts, Private messages, Wall post comments
  • No Core File Modifications
    Integrates cleanly through Q2A layers and services without modifying Question2Answer core files.
  • Lightweight & Theme Friendly
    Designed to work with existing Q2A themes and editor plugins while keeping frontend assets minimal.

Requirements

  • Q2A version: 1.8+ (older versions untested)
  • Compatible Editors: Markdown, WYSIWYG (other editors untested)
  • WPC plugin required for wall post comment editor support
